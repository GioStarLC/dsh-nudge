# 语音批注接入 — 调研记录

> **状态：未接入。** 仓库里没有任何 voice 相关代码——`client.js`、`index.js`、`scripts/` 都搜不到 `voice` / `parseCombo` / `OimeVoice`。
> 本文只保留调研结论与实测证据，供下次接手时不必重跑一遍。

## 一、结论

- 豆包（Windows 版）的语音快捷键只监听**驱动层**。任何**应用层**合成输入（`SendInput`、罗技宏、Ulanzi 键盘、`PostMessage`）都不会触发它。
- 依据：① Ulanzi 官方说明 https://bbs.ulanzistudio.com/thread-159-7-1.html ；② 本机实测（见第二节）。
- 推论：**软件模拟按键这条路走不通**。只能换输入法、加 HID 硬件、装内核驱动，或保持手动按一次。

## 二、实测证据（别再重复这些）

1. 键盘钩子抓到合成事件：`down vk=165 scan=0x38 ext=1 injected=1`（与物理右 Alt 逐位一致，仅多 `injected`）。
2. 有一次注入确实让豆包弹出了 `OimeVoiceWaveWindow`；此后在同样的卡片流程里再未复现。
3. 日志证明发送侧执行正确：`15:41:44 down sent=1` → `15:41:45 up sent=1`（1.2 秒后松开）。
4. 罗技鼠标宏发 `Ctrl+B` → 触发了 DSH 自己的快捷键，**没触发豆包**，与「应用层能到、驱动层收不到」一致。
5. Sayo 设备：真 HID 键盘（记事本里读到 `3333222221111111`），但它是**输入设备**，电脑不能命令它按键。

已排除的做法：换键位（会撞应用快捷键）、AutoHotkey/SendInput 各变体、`PostMessage`（同属应用层）、UI Automation 点豆包的麦克风按钮（豆包 IME 面板是 DirectUI，UIA 只暴露它的设置页）。

## 三、可选路径（按代价排序）

1. **手动（当前做法，零风险）**：划选 → 批注卡片 → 按右 Alt 说话 → 点「添加批注」。键盘只多这一次按键。
2. **换走应用层的语音输入法**：讯飞 / 搜狗 / 百度 / 微信语音输入法 / Typeless。全自动只卡在「点一下就让输入法开始收音」这一步，换输入法即通。
3. **HID 硬件桥（全自动的可行解）**：CH9329（串口转键盘）或 Raspberry Pi Pico。电脑经串口发「按下/松开右 Alt」，模块作为真键盘发键；免驱、无需管理员、对系统零改动。
4. **Interception 内核驱动**：需管理员，键盘过滤驱动；本机有奇安信，大概率被拦；驱动出问题会影响全局键盘。
5. **逆豆包 IPC**（`\\.\pipe\ObricIme\oime-server`）：无公开协议，版本升级即失效，需先抓包验证。

## 四、环境注意

- 本机同时装了搜狗与豆包两个输入法，默认可能是搜狗；**每个窗口挂哪个 IME 需单独确认**（在备注框打一个字母看候选条是谁的）。
- 奇安信（QAX）在运行，可能拦截驱动安装或注入类行为。
- 插件以软链方式安装在 `~/.dsh/profiles/desktop/node_modules/dsh-nudge` → 仓库根；**宿主半部改动需重启 DSH**，浏览器半部刷新页面即可。

## 五、若要接入，落点在哪

- **设置项**：插件自己的设置项都登记在 `client.js` 的 `SETTINGS` 表里（存储键 / 解码 / 编码 / 线上名），新增一项 = 表里加一行 + 设置页控件；启动态与回灌会跟着走，不用另写读取逻辑。
- **拉起按键必须由宿主半部发**（页面发不了系统按键）。新路由挂在 `index.js` 已有的 loopback 前缀下，并延续两条不变量：只答 loopback、按白名单校验载荷。宿主侧新字段还要补 `index.js` 的 `pickStore`（`scripts/check-host.mjs` 会核对 `STORE_KEYS` 与它是否一致）。
- **检查写在 `scripts/check-client.mjs`**：那里已经有走真实 `index.js` 路由的桥接检查（`bridge:` 开头的条目，用临时 profile 目录落真实文件），新增路由照这个形态接，不必新开脚本。
- **卡片**：批注卡片的状态现在由 `IDLE_ANNOTATION` 与 `settleAnnotation` / `commitAnnotations` 统一收口，「正在听 / 失败原因」这类临时状态应作为卡片字段加到那一处，而不是各处 setState 各拼一份。

## 六、接入后的验收标准

- 设置页点「测试一次」→ 宿主侧记录 `lastPressAt`，日志出现 `down sent=1` / `up sent=1`。
- 卡片点麦克风后 0.7 秒内，能报出输入法是否真的起了语音窗口。
- 走应用层输入法或硬件桥时，卡片能收到语音文字并写入备注框。
